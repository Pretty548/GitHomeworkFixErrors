## 2. What is JavaScript?

A high level, versatile programming language most commonly used to make websites interactive and dynamic

## 3. What three problems does Git & GitHub solve?

Tracking changes over time, collaboration, backup and remote access

## 4. What happens when you `fork` a repository?

Github makes a duplicate of the original and the copy appears in your account. you can change it, experiment or build on it freely

## 5. What happens when you clone a repository?

Git copies all files and brings the entire version history. you get fully working local Git repo on your computer and the cloned repo still tracks the original so you can pull updates or push changes

## 6. What is a Pull Request?

It is a way to propose changes to someone else's codebase on Github
